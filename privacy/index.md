# プライバシーポリシー

本アプリ「みちこれっ！」（以下「本アプリ」といいます）を運営する個人（以下「運営者」といいます）は、利用者の情報の取扱いについて、以下のとおりプライバシーポリシー（以下「本ポリシー」といいます）を定めます。

本アプリは、特定の個人を識別できる情報（氏名、メールアドレス、電話番号など）を取得しない設計としています。利用者の区別には、アプリが自動で発行する利用者ID（下記第1条）を使います。ただし、お問い合わせなどで運営者が個人情報を受け取った場合は、本ポリシーに従って取り扱います。

## 1. 取得する情報および利用目的

運営者は、以下の情報を、それぞれの目的に必要な範囲で取得・利用します。

### 運営者のサーバーに保存する情報

| 取得する情報 | 内容 | 利用目的 |
| --- | --- | --- |
| 利用者ID | Firebase の匿名認証で発行されるID。氏名・メールアドレス等とは結び付いていません | 利用者の区別、ログイン |
| アカウントの情報 | 登録日時・更新日時、最後に利用した日付（日単位）、ランキングへの参加の設定 | アカウントの管理、一定期間利用のないデータの削除（第8条） |
| 有料プランの利用状況 | 契約中の有料プランの種類 | 有料プランの機能の提供 |
| 踏破履歴 | 通過した国道の区間と通過した日付（日単位）、国道ごとの踏破の集計と更新日時。速度は保存しません | 踏破状況・称号・ランキングの表示 |
| 称号・レベル | 獲得した称号と獲得日時、称号のピン留めの設定と日時、レベル | 称号・レベルの表示 |
| プッシュ通知用のトークン | 通知の送信先のトークン、端末のOSの種類、アプリのバージョン | プッシュ通知の送信 |
| SNSでのシェアの記録 | シェアした SNS の種類・画面・国道番号、本文、シェア用の画像、短縮URL、日時 | シェア用のページ・画像の提供 |
| 引き継ぎ用の値（ハッシュ） | 自動の引き継ぎに使う値を、元に戻せない形（ハッシュ）にしたもの | 再インストール・機種変更時の自動の引き継ぎ（第6条） |
| お問い合わせの内容 | 問い合わせフォームで入力された種類・内容、運営者とのやり取り（回答・返信）と日時、対応の状態、一緒に送信される利用者ID（画面には表示しません） | お問い合わせへの回答、開示等の請求への対応 |
| 判定に失敗した位置情報（一時保持） | サーバーの障害などで踏破の判定に失敗した場合に限り、送信された位置情報（緯度・経度・記録日時）。最長14日間で削除します（下記の※） | 踏破の判定の再処理 |
| 退会後の削除処理の記録 | 退会時に外部のサービスのデータの削除に失敗した場合に限り、利用者IDと退会した日（日単位） | 外部のサービスのデータの削除の再試行（第8条） |
| 通信の記録 | アクセスログ（送信元IPアドレスは末尾を伏せた形、User-Agent、アクセスしたURL。URL に含まれる位置情報は伏せます） | 不正利用の防止、障害の調査 |

※ **位置情報**：端末で取得した位置情報（GPSの座標）は、通過した国道の区間を判定するためにサーバーへ送信し、判定後は保存しません。保存するのは、上記の「踏破履歴」（通過した区間と日付）だけです。ご自宅の場所や、特定の時刻にいた場所は記録しません。ただし、サーバーの障害などで判定に失敗した場合に限り、再処理のため、送信された位置情報（緯度・経度・記録日時）を最長14日間保持し、再処理の完了後または期間の経過後に削除します。

※ **送信元IPアドレス**：上記の通信の記録のほか、自動の引き継ぎ（第6条）の試行回数を制限するため、送信元IPアドレスをサーバーのメモリ上でだけ使います（保存しません）。

※ **SNSでのシェア用の画像**は、SNS で共有できるよう、URL を知っていれば誰でも見られる場所に保存します。

※ ランキングでは、他の利用者の情報（利用者ID・称号など）は表示しません。表示するのは、ご自身の順位と、1つ上の順位までの差だけです。ランキングは「ランキングへ参加する」を有効にした利用者の値で集計し、無効にすると集計の対象から外れます。

### 端末内にだけ保存し、運営者が取得しない情報

投稿した写真、プロフィール画像、端末内の踏破履歴の通過時刻・速度は、お使いの端末内にだけ保存し、運営者のサーバーには送信しません。アプリを削除すると消え、機種変更時にも引き継がれません。

### 外部のサービスが取得する情報

本アプリが利用する外部のサービスは、各サービスの提供のため、以下の情報を取得します（第3条・第4条）。

| 取得する情報 | 送信先 | 利用目的 |
| --- | --- | --- |
| 利用者ID | Google（Firebase Authentication）、RevenueCat | ログイン、有料プランの購入状況の管理 |
| 購入履歴 | RevenueCat、App Store／Google Play | 有料プランの購入の検証・管理。カード番号等の決済の情報は運営者が取得しません |
| アプリの利用状況・クラッシュの情報 | Google（Firebase Analytics・Crashlytics） | 利用状況の把握、不具合の調査。位置情報は送信しません |
| エラーの情報 | Sentry | サーバーの不具合の調査。送信元IPアドレス・位置情報は送信しません |
| 広告識別子（IDFA・広告ID）、IPアドレス等の端末の情報 | Google（AdMob） | 広告の配信・効果測定（第5条） |
| 端末の情報、IPアドレス、地図の表示範囲（利用者が地図の「i」ボタンから利用状況の統計の送信を有効にした場合は、位置情報等も） | Mapbox | 地図の表示（有効にした場合は、地図サービスの利用状況の統計） |
| 引き継ぎ用の値 | Apple（iCloud キーチェーン）、Google（Block Store） | 自動の引き継ぎ（第6条） |

## 2. 第三者への提供

運営者は、次の場合を除き、取得した情報を第三者に提供しません。

- 法令に基づく場合
- 人の生命・身体・財産の保護のために必要で、本人の同意を得ることが難しい場合
- 第1条・第3条・第4条に記載した外部のサービスに、サービスの提供に必要な範囲で取扱いを委託する場合

広告識別子などの「個人関連情報」は、本アプリに組み込んだ Google AdMob の仕組みにより、Google が直接取得します（第5条）。運営者が、利用者を識別できる情報と結び付けて提供することはありません。

## 4. 外部送信について

本アプリは、以下のとおり、利用者の端末から外部のサービスへ情報を送信します。この節は、電気通信事業法第27条の12に定める外部送信に関する事項の公表を兼ねます。

| 送信先 | 送信する情報 | 目的 |
| --- | --- | --- |
| Google LLC（Firebase Authentication） | 利用者ID、端末の情報 | ログイン |
| Google LLC（Firebase Cloud Messaging） | プッシュ通知用のトークン | プッシュ通知の送信 |
| Google LLC（Firebase Analytics・Crashlytics） | アプリの利用状況、クラッシュの情報、端末の機種・OSのバージョン | 利用状況の把握、不具合の調査 |
| Google LLC（AdMob） | 広告識別子、IPアドレス、端末の情報 | 広告の配信・効果測定 |
| RevenueCat, Inc. | 利用者ID、購入履歴、端末の情報 | 有料プランの購入状況の管理 |
| Mapbox, Inc. | 端末の情報、IPアドレス、地図の表示範囲（利用状況の統計の送信を有効にした場合は、位置情報等も。本アプリは起動時に無効にします） | 地図の表示（有効にした場合は、利用状況の統計） |
| Apple Inc.（iCloud キーチェーン）、Google LLC（Block Store） | 引き継ぎ用の値 | 自動の引き継ぎ（第6条） |

## 5. 広告識別子とトラッキングについて

本アプリは、無料プランの範囲で、Google AdMob による広告を表示します。AdMob は、広告の配信・最適化・効果測定のため、広告識別子（iOS：IDFA、Android：広告ID）や IPアドレス等の端末の情報を利用する場合があります。

iOS では、Apple の「App Tracking Transparency（ATT）」により、他社のアプリやウェブサイトを横断したトラッキングの許可を求めるダイアログを表示します。許可しない場合でも、本アプリの機能はすべて利用できます。

広告のパーソナライズを希望されない場合は、端末の設定から広告識別子のリセットやパーソナライズ広告の無効化ができます。

- iOS：「設定」→「プライバシーとセキュリティ」→「トラッキング」
- Android：「設定」→「プライバシー」→「広告」

## 6. 自動の引き継ぎについて

本アプリは、再インストールや機種変更のときに、データを自動で引き継ぎます。

- 引き継ぎ用の値（個人を特定する情報を含まない乱数）を、iOS では iCloud キーチェーン、Android では Block Store に保存します。この値は、OS の仕組みにより、利用者の Apple ID・Google アカウントに紐付いて同期・バックアップされます。運営者は、この値を元に戻せない形（ハッシュ）でだけ保存します。
- 次の場合は引き継げず、新しい利用者として始まります。
  - iOS と Android の間の機種変更
  - iCloud キーチェーン、または Google アカウントのバックアップを無効にしている場合
  - 退会した場合
- Apple ID・Google アカウントを複数の方で共有している場合、再インストールした端末が、共有している別の方のデータに戻ることがあります。
- 引き継げなかった元のデータは、第8条の期間の経過後に削除します。

## 7. 開示・訂正・利用停止等の請求

<a id="data-deletion"></a>

### アカウントとデータの削除

退会（アカウントと、それに紐付くデータの削除）は、アプリ内のプロフィール画面からいつでも行えます。退会すると、運営者のサーバーのデータに加え、外部のサービス（Firebase Authentication、RevenueCat）のデータとシェア用の画像も削除します。

- **アプリを削除した後に、データの削除を希望される場合**：本アプリを再インストールしてください。同じ Apple ID（iCloud キーチェーンがオン）または同じ Google アカウント（バックアップがオン）の端末であれば、元のデータに自動で戻ります（第6条）。戻った後に、アプリ内の退会機能から削除してください。元のデータに戻らない場合は、ご本人のデータを特定できないため、個別の削除には応じられません。その場合も、最後の利用から1年間で自動で削除します（有料プランを契約中の場合を除きます。第8条）。
- **有料プランの自動更新**：退会しても、App Store・Google Play の定期購入は停止しません。退会の前に、各ストアの定期購入の設定から解約してください。

保有個人データの利用目的の通知、開示、訂正・追加・削除、利用停止・消去、第三者への提供の停止、第三者提供記録の開示（以下「開示等」といいます）を請求される場合は、本アプリ内の問い合わせフォーム（プロフィール画面の「お問い合わせ」）からご連絡ください。

- **本人確認**：本アプリは氏名等を取得しないため、問い合わせフォームが問い合わせと一緒に送信する利用者IDにより、ご本人のデータを特定します。問い合わせフォーム以外（メール等）でのご請求では、ご本人のデータを特定できないため、開示等に応じられないことがあります。
- **手数料**：無料です。
- **回答の方法**：本アプリ内（プロフィール画面の「お問い合わせ」）で回答し、プッシュ通知でお知らせします。通知には、お問い合わせの内容を含めません。


## 8. 保存期間

| 情報 | 保存期間 |
| --- | --- |
| アカウント・踏破履歴などのサーバーのデータ | 退会するまで。ただし、最後の利用から1年間利用がない場合は、運営者のサーバー・ストレージ・Firebase Authentication・RevenueCat のデータを自動で削除します（有料プランを契約中の場合を除きます） |
| 判定に失敗した位置情報 | 最長14日間（第1条） |
| お問い合わせの内容 | 運営者が対応済みにしてから10日間（回答・返信を含めて削除します）。退会・自動の削除の際にも削除します |
| 退会時の外部のサービスの削除に失敗した場合の記録 | 削除が完了するまで（利用者IDと退会した日だけを保存し、毎日再試行します） |
| アクセスログ | ログのローテーションにより、古いものから順に削除します（保存期間はアクセス量により変わります） |
| バックアップ | 障害に備えたバックアップには、削除後も約35日間残ります |

次の操作では、運営者のサーバーのデータは削除されません。データを削除するには、アプリ内の退会機能をご利用ください。

- 本アプリのアンインストール
- iCloud キーチェーン・Google アカウントのデータの削除

## 9. 安全管理措置

運営者は、取り扱う情報の漏えい・滅失・毀損を防ぐため、次の措置を講じています。

- **組織的・人的な措置**：取扱いは運営者本人だけが行い、取扱いの方法を本ポリシーと運用の手順書で定めています。
- **物理的な措置**：サーバーはデータセンターで運用され、運営者の端末はパスワード等で保護しています。
- **技術的な措置**：通信を暗号化（HTTPS）し、サーバーへのアクセスを制限しています。ログ・エラーの監視には、位置情報や送信元IPアドレスの全体を残さないようにしています。
- **外的環境の把握**：外国の事業者のサービスを利用するにあたり、第3条のとおり、その国の制度を把握したうえで安全管理措置を講じています。
