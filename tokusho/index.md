# 特定商取引法に基づく表記

本アプリ「みちこれ！」における有料プラン(パスポートプラン)の提供にあたり、特定商取引法第11条に基づき、以下の通り表示いたします。

| 項目 | 内容 |
| --- | --- |
| 販売事業者 | ※ 屋号または「個人事業主 ○○ ○○」の形式でご記入ください |
| 運営統括責任者 | ※ 運営者ご本人のお名前をご記入ください |
| 所在地 | ※ 下記「所在地・電話番号の開示について」をご参照の上ご記入ください |
| 電話番号 | ※ 下記「所在地・電話番号の開示について」をご参照の上ご記入ください |
| お問い合わせ先 | support@michicolle.jp |
| 受付時間 | ※ メール対応のみの場合は「メールでの受付は24時間、回答は原則3営業日以内」等をご記入ください |
| 販売価格 | パスポートプラン(年額):1,000円(税込) パスポートプラン(月額):100円(税込) |
| 商品代金以外の必要料金 | 通信費等はお客様のご負担となります |
| 支払方法 | Apple App StoreまたはGoogle Playを通じたアプリ内課金 |
| 支払時期 | 購入手続き完了時に、各アプリストアの決済方法に基づき課金されます |
| 引渡し時期 | 決済完了後、直ちに有料プランの機能をご利用いただけます |
| 返品・キャンセルについて | デジタルコンテンツの性質上、購入後の返金には対応しておりません。サブスクリプションの解約は、各アプリストアの設定画面からいつでも行うことができます。返金をご希望の場合は、購入手続きを行った各アプリストア(Apple App StoreまたはGoogle Play)へ直接お申し出ください |
| 動作環境 | 各アプリストアに記載の対応OSバージョンをご確認ください |

## 所在地・電話番号の開示について

特定商取引法上、個人事業主が通信販売を行う場合、原則として所在地・電話番号の表示が必要ですが、消費者庁の解釈では、以下のいずれかの対応を行うことで、これらの情報をご請求に応じて開示する形とし、本ページ上への常時掲載を省略できるとされています。

- 「請求があれば遅滞なく開示します」という一文を掲載し、請求があった場合には電子メール等で遅滞なく所在地・電話番号を開示する
- ネットショップ運営者向けの私書箱・バーチャルオフィスサービス等を利用し、当該住所・電話番号を表示する

御社が個人事業主として、ご自宅住所の公開を避けたい場合は、上記いずれかの方法をご検討ください。その場合、上表の「所在地」「電話番号」の欄には、以下のような一文を記載する形になります。

> 所在地・電話番号については、請求があり次第、遅滞なく電子メールにて開示いたします。ご請求は下記お問い合わせ先までご連絡ください。

※ この取り扱いが実際に認められるかどうかは、事業の実態や取引形態によって判断が分かれる場合があるため、正式な運用にあたっては、最終的に消費生活センターや専門家(行政書士・弁護士等)にご確認いただくことを推奨します。本ページはその判断を代替するものではありません。
